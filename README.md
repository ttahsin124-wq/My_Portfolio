## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/portfolio.git

# Navigate into the project folder
cd portfolio

# Open index.html in your browser
```

No build tools or dependencies required — just open `index.html` directly, or use a tool like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for auto-reload during development.
